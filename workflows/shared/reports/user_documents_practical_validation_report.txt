====================================================================================================
BUGS & DISCOVERIES FOUND DURING PRACTICAL TESTING
====================================================================================================

BUG 1: SILENT UPLOAD REJECTION FOR VERIFIED USERS
- Severity: MEDIUM
- Description: When a user's document status is Verified (averified=1), the admin upload endpoint
  uploadserver.php silently rejects file uploads without any error message. The admin UI shows
  success confirmation, but the file does not persist. Admin must set user to Not Verified before
  uploading documents.
- Recommendation: Show a clear error message when upload is attempted on a Verified user.

BUG 2: MODAL OVERLAY BLOCKING (jconfirm / Bootstrap)
- Severity: LOW (UI/UX)
- Description: The jconfirm library and Bootstrap #deleteModal can leave persistent overlays that
  block all pointer events on the page. This occurs when modals are not properly dismissed after
  confirmation dialogs, especially during rapid sequential operations.
- Recommendation: Add proper cleanup handlers that remove .modal-backdrop and modal-open class.

NOTE 1: CASE SENSITIVITY IN CLIENT PORTAL REMARKS
- Description: The client portal displays 'Remarks' (title case) while admin uses 'REMARKS'
  (uppercase). Tests should use case-insensitive matching for cross-portal text assertions.
