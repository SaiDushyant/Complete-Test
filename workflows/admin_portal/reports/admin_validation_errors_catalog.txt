## 2. SUMMARY OF VALIDATION DEFENSES & SAFEGUARDS

1. **Input Format Constraints**: HTML5 type restrictions (`number`, `email`, `datetime-local`) prevent malformed date strings, negative lot sizes, and alphabetical strings in numeric columns.
2. **Financial Invariant Safeguards**: Overdraft prevention blocks withdrawal approvals when user equity < withdrawal amount. Bonus grants require strictly positive values (> $0.00).
3. **MIME Type Security**: File dropzones on Leads and Deposit Proofs enforce `.csv`, `.xlsx`, `.png`, `.jpg`, `.pdf` extensions; blocking `.exe`, `.php`, and `.sh` file uploads.
4. **KYC Audit Trails**: Document rejection requires a mandatory remark before the admin can transition document status to 'Rejected'.
5. **Upper Bound Caps**: Referral share percentages are capped at 100%; MAM/PAMM allocation sums cannot exceed 100% of follower pool.
